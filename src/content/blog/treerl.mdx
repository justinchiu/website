There have been a couple papers on branching rollouts in LLM RL ([TreeRL](https://arxiv.org/abs/2506.11902)), as well as Monte Carlo value estimates ([VinePPO](https://arxiv.org/abs/2410.01679)).
TreeRL branches during sampling and trains on the whole tree.
VinePPO's Monte Carlo continuations give unbiased values, but they are only used to estimate values and are never actually trained on.
In this blog post, we derive the tree policy gradient estimator so you can learn from branches with confidence.

# Policy gradient

The policy $\pi_\theta$ generates tokens $x = x_1\ldots x_T$ and gets terminal reward $r(x)$.
At position $t$, the state is $s_t = x_{<t}$, the action is $a_t = x_t$, and the future tokens $x_{>t}$.
The action-value function $Q(s,a) = E_{p(y\mid s,a)}[r(s,a,x_{>t})]$ and value function $V(s) = E_{p(a\mid s)}[Q(s,a)]$.
The policy gradient is

$$
\begin{align}
\nabla E_{p(x)}[r(x)]
&= E_{p(x)}\Big[r(x) \sum_t \nabla\log p(a_t\mid s_t)\Big]\\
&= \sum_t E_{p(s_t)p(a_t\mid s_t)}\big[Q(s_t,a_t)\,\nabla\log p(a_t\mid s_t)\big]\\
&= \sum_t E_{p(s_t)p(a_t\mid s_t)}\big[\big(Q(s_t,a_t) - V(s_t)\big)\,\nabla\log p(a_t\mid s_t)\big].
\end{align}
$$

This is straightforward to apply to a chain with terminal reward: treat the whole chain as a single action. Note that this only works if we assume a discount factor of 1, which we usually do with LLMs.
